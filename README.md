# librarymanagementcpp

A complete Library Management System developed in C++ using Object-Oriented Programming and File Handling.

## Features

- Add Books
- Delete Books
- Search Books
- Update Books
- Issue Book
- Return Book
- Statistics
- Persistent Storage
- Admin Login

## Technologies

- C++
- STL
- OOP
- File Handling

## Run

g++ src/*.cpp -o library

./library
